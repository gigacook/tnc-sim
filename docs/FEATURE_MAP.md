## About this file

This is the inventory for the dual-frontend redesign, so that nothing gets lost. One row is one function a user can
see or trigger.

- **Old location** describes the starting commit `c6e6e7d`, read with `git show c6e6e7d:<path>`. It does not
  describe the working tree.
- **New location** describes the working tree of branch `feat/dual-frontend` on 2026-11-18: where the function is
  now, and the key or menu path to it. "unchanged:" means the same id and the same handler as at `c6e6e7d`.
  "removed by design" quotes the spec or doc line that states the removal. `NOT FOUND (see top)` points to the
  list above.
- **Regression coverage (this branch)** names tests as they are in the working tree on 2026-11-18, found by
  reading or grepping the test files; the tests were not run for this file. A check name of `c6e6e7d` that no
  longer exists is named as gone. `none found` means no test was found for that function; it does not mean the
  function is broken. Parts of a name that the test fills in at run time are written in brackets, as in (n) or
  (language).
- The engine was not changed by the redesign: `git diff --stat c6e6e7d -- server/crates/tnc-core sim/engine`
  prints nothing.
